🎯 PROBLEMA RESOLVIDO:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ao importar dados de planilhas Excel, nem todos os registros estavam sendo
importados. O sistema perdia registros válidos quando havia erros em alguns
itens, deixando uma quantidade relevante de dados sem serem processados.

EXEMPLO: Importando 1000 férias, apenas 500 eram importadas se 1 delas 
         tivesse um erro. As outras 499 válidas eram perdidas.

✅ SOLUÇÃO IMPLEMENTADA:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Criada função resiliente: processarComResiencia()
   └─ Processa CADA item individualmente
   └─ Captura erros de forma isolada
   └─ Continua com próximo item mesmo com falha anterior
   └─ Retorna estatísticas completas

2. Aplicada em TODOS os métodos de importação:
   ├─ ✅ Férias (ImportFeriasButton)
   ├─ ✅ Faltas (ImportFaltasButton → upsertFaltasBatch)
   ├─ ✅ Colaboradores (ImportColaboradoresButton → applyImport)
   ├─ ✅ Colaboradores (importarColaboradores server function)
   └─ ✅ Agendamentos (ImportAgendamentosButton)
